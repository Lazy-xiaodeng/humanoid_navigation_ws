## 使用建议

如果后续继续补充控制台业务文档，建议统一放在本目录下，包括：

1. 前端实施说明
2. 后端网关说明
3. JSON 消息清单
4. 评审记录
5. 排期表格
6. UI 资源图

这样能避免与 ROS 导航系统源码、运行配置、launch、脚本等内容混在一起。
