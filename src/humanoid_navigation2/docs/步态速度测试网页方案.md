# 步态速度测试网页方案

目标：给第二组实验提供一个轻量测试面板。

页面能力：

- 输入目标线速度和角速度
- 点击开始后通过 WebSocket 下发测试命令
- ROS 节点持续向 `/cmd_vel` 发布速度
- 页面实时显示机器人真实轨迹、真实速度、速度曲线、统计值和日志

## 1. 启动顺序

先加载工作空间环境：

```bash
cd /home/ubuntu/humanoid_ws
source /opt/ros/jazzy/setup.bash
source install/setup.bash
```

启动 WebSocket 服务：

```bash
ros2 launch humanoid_websocket websocket_server.launch.py
```

启动测试监控节点：

```bash
ros2 launch humanoid_navigation2 gait_velocity_test_monitor.launch.py
```

## 2. 打开页面

本机直接打开：

```text
/home/ubuntu/humanoid_ws/debug_monitor/gait_velocity_test_monitor.html
```

如果要让手机访问：

```bash
cd /home/ubuntu/humanoid_ws/debug_monitor
python3 -m http.server 8080
```

然后手机浏览器打开：

```text
http://机器人IP:8080/gait_velocity_test_monitor.html
```

页面中的 WebSocket 地址填：

```text
ws://机器人IP:8765
```

## 3. 页面操作

1. 点击“连接”
2. 点击“发送订阅”
3. 输入目标线速度，例如 `0.60`
4. 点击“开始测试”
5. 观察真实速度、轨迹、速度曲线和日志
6. 点击“结束测试”

## 4. WebSocket 命令格式

页面实际发送的是已有 `robot_control` 命令通道，参数如下：

```json
{
  "message_type": "command",
  "data_type": "robot_control",
  "data": {
    "action": "gait_velocity_test",
    "parameters": {
      "action": "start",
      "linear_x": 0.6,
      "angular_z": 0.0
    }
  }
}
```

停止时：

```json
{
  "message_type": "command",
  "data_type": "robot_control",
  "data": {
    "action": "gait_velocity_test",
    "parameters": {
      "action": "stop"
    }
  }
}
```

## 5. ROS 侧数据来源

- 控制输出：`/cmd_vel`
- 实际位姿：`/robot_realpose`
- 备用速度：`/odom`
- 页面推送：`/integration/push_messages`

推送数据类型：

```text
gait_velocity_test
```

## 6. 适合当前实验的用途

- 用网页组模拟“固定线速度匀速走路”
- 记录不同目标速度下真实平均速度
- 对比遥控器实验组和网页驱动实验组的步态差异
- 验证“低速更碎步、步态更不好看”的假设是否成立
