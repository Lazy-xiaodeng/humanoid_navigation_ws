# 节点实现功能简表

整理时间：2026-06-04  
用途：面向项目汇报，按系统模块说明当前工作区各节点已经实现的业务功能。  
说明：本文只说明“实现了哪些功能”，不展开代码位置和实现细节。

## 1. APP 通信与 WebSocket 服务

### WebSocket 服务端节点：`websocket_server`

服务端主要负责 APP 与机器人 ROS 系统之间的统一通信。

客户端连接能力：

- 支持 APP 建立 WebSocket 连接。
- 支持多个 APP 客户端同时连接。
- 支持连接确认，连接后返回客户端 ID、协议版本和支持的功能列表。
- 支持心跳检测，用于判断 APP 是否在线。
- 支持客户端断开后的连接清理。
- 支持 APP 按需订阅指定数据。

APP 指令接收能力：

- 支持接收点位管理指令。
- 支持接收导航控制指令。
- 支持接收机器人动作控制指令。
- 支持接收面部表情控制指令。
- 支持接收初始位姿设置指令。
- 支持接收实时数据查询请求。

指令转发能力：

- 可将 APP 的点位新增、修改、删除、查询等命令转发给点位管理节点。
- 可将 APP 的单点导航、多点导航、暂停、继续、终止等命令转发给导航管理节点。
- 可将 APP 的动作控制命令转发给动作控制链路。
- 可将 APP 的表情命令转发给表情驱动节点。
- 可将 APP 设置的初始位姿转成 ROS 导航系统可用的初始定位消息。

数据推送能力：

- 支持向 APP 推送机器人当前位置。
- 支持向 APP 推送机器人速度。
- 支持向 APP 推送导航状态。
- 支持向 APP 推送路径规划信息。
- 支持向 APP 推送系统状态。
- 支持向 APP 推送点位数据。
- 支持向 APP 推送动作执行结果。
- 支持向 APP 推送表情库数据。
- 支持向 APP 推送定位异常、导航异常、障碍物阻塞等事件。

### WebSocket 客户端节点：`websocket_client`

客户端主要负责 ROS 系统与机器人本体或外部控制服务之间的数据交互。

- 支持连接机器人本体侧服务。
- 支持接收机器人本体状态。
- 支持转发机器人本体数据到 ROS 系统。
- 支持把 ROS 侧控制命令发送给机器人本体。
- 支持作为 APP 服务端与机器人本体之间的桥接通道。

### 数据整合节点：`data_integration_node_recoverable`

数据整合节点主要负责把 ROS 内部多个节点的数据整理成 APP 能直接使用的数据。

- 整合机器人实时位置。
- 整合机器人实时速度。
- 整合导航状态和导航进度。
- 整合当前目标点、当前导航序列和已完成点位。
- 整合全局路径和局部路径。
- 整合系统状态，例如电量、急停、控制状态等。
- 整合点位数据和点位变更结果。
- 整合动作执行结果。
- 整合表情库列表。
- 支持 APP 主动查询数据。
- 支持按 APP 订阅频率周期性推送数据。
- 支持导航事件实时推送，例如开始、暂停、恢复、完成、失败、阻塞。
- 支持定位异常事件推送，例如定位丢失、自动暂停、自动恢复。
- 支持动作事件推送，例如动作开始、完成、超时、失败。

### 消息桥接节点：`message_bridge`

消息桥接节点主要负责将机器人本体原始数据转换成系统内部统一可用的数据。

- 解析机器人本体原始状态。
- 解析电池状态。
- 解析急停状态。
- 解析机器人当前控制模式。
- 解析机器人是否正在执行动作。
- 转换 IMU 数据。
- 转换关节状态数据。
- 将处理后的机器人状态提供给导航系统和 APP。
- 辅助导航系统判断机器人当前是否允许开始导航。

## 2. 导航业务管理系统

### 动态点位管理节点：`dynamic_waypoints_manager`

该节点负责 APP 侧点位的管理，是“目标点数据库”和“导航请求入口”。

点位管理功能：

- 支持新增目标点。
- 支持修改目标点。
- 支持删除目标点。
- 支持查询目标点。
- 支持清空目标点。
- 支持按类型管理目标点。
- 支持本地保存点位数据。
- 支持系统重启后恢复已保存点位。

点位类型能力：

- 支持普通导航目标点。
- 支持展台讲解点。
- 支持充电点。
- 支持休息点。
- 支持地标点。
- 支持障碍物点或辅助标记点。

点位属性能力：

- 支持设置点位名称。
- 支持设置点位坐标。
- 支持设置点位朝向。
- 支持设置点位说明。
- 支持设置点位颜色，便于 APP 或可视化区分。
- 支持设置点位停留时间，适合展台讲解、定点等待。
- 支持设置目标点行走方向，可选择正着走或倒着走。
- 支持设置目标点导航速度。
- 支持每个目标点单独设置速度。
- 支持对点位速度做合法性校验，避免设置过低或过高导致机器人异常。

导航请求能力：

- 支持单点导航请求。
- 支持多点导航请求。
- 支持展台巡航请求。
- 支持导航前检查点位是否存在。
- 支持把合法导航请求转发给导航状态管理节点。
- 支持向 APP 返回点位管理结果。
- 支持向 APP 推送点位数据更新。

### 导航状态管理节点：`navigation_state_manager`

该节点是 APP 导航控制的核心节点，负责实际执行导航和维护导航状态。

基础导航能力：

- 支持单点导航。
- 支持多点连续导航。
- 支持展台巡航导航。
- 支持从点位数据库读取目标点。
- 支持导航到当前点后自动切换到下一个点。
- 支持记录当前导航模式。
- 支持记录当前目标点。
- 支持记录当前点位序号和总点位数量。
- 支持计算导航进度。
- 支持计算剩余距离。
- 支持估算剩余时间。

导航控制能力：

- 支持开始导航。
- 支持暂停导航。
- 支持继续导航。
- 支持终止导航。
- 支持导航失败后重试当前目标点（预留接口待实现）。
- 支持导航失败后跳过当前目标点（预留接口待实现）。
- 支持导航失败后终止整个任务。
- 支持导航过程中接收新的控制命令。
- 支持导航状态实时上报给 APP。

多点与展台导航能力：

- 支持 APP 下发多个目标点形成导航序列。
- 支持按目标点顺序依次导航。
- 支持展台点自动组成巡航路线。
- 支持到达某个点后上报到点事件。
- 支持整个序列完成后上报完成事件。
- 支持记录已跳过点位和失败点位。

速度控制能力：

- 支持系统默认导航速度。
- 支持导航系统内部配置行走速度。
- 支持导航系统内部配置转弯速度。
- 支持每个目标点单独设置期望行走速度。
- 支持根据目标点属性读取速度要求。
- 支持将过低、过高的点位速度设置识别为无效配置。
- 支持接近目标点时减速。
- 支持转弯时按曲率降低速度，提高行走稳定性。

正走/倒走能力：

- 支持普通目标点正着走。
- 支持目标点配置倒着走。
- 支持根据点位属性自动选择正走或倒走。
- 支持普通导航禁止倒车，降低后方无传感器带来的风险。
- 支持特殊倒走点使用专门的倒走导航逻辑。
- 支持定位恢复后，如果当前点位位于机器人身后，可选择倒走续航。

暂停与恢复能力：

- 支持 APP 手动暂停导航。
- 支持 APP 手动恢复导航。
- 支持暂停后保留当前目标点和导航进度。
- 支持恢复后继续前往未完成目标点。
- 支持定位异常时自动暂停导航。
- 支持定位恢复稳定后自动继续导航。
- 支持定位恢复期间拒绝 APP 手动恢复，避免误操作。

终止与失败处理能力：

- 支持 APP 主动终止导航。
- 支持 Nav2 失败后进入可处理状态。
- 支持失败点位重试。
- 支持失败点位跳过。
- 支持失败后向 APP 返回可选操作。
- 支持导航终止后重置导航状态。

避障与异常上报能力：

- 支持实时监控机器人是否正在移动。
- 支持判断机器人是否被障碍物长时间挡住。
- 支持设置障碍物阻塞等待时间。
- 支持超过等待时间后向 APP 上报障碍物阻塞。
- 支持接近目标点时抑制误报。
- 支持机器人执行动作或原地转向时抑制误报。
- 支持向 APP 推送“前方路径被挡住”等提示。
- 支持上报异常但不强制取消导航，便于现场人工确认。

机器人状态联动能力：

- 支持读取机器人当前控制状态。
- 支持判断机器人是否处于可导航模式。
- 支持机器人正在执行动作时暂缓导航。
- 支持等待动作结束后再启动导航。
- 支持防止动作执行和导航执行互相冲突。

## 3. Nav2 底层导航能力

### 地图服务器：`map_server`

- 加载室内 2D 栅格地图。
- 发布导航使用的静态地图。
- 给全局路径规划提供地图基础。
- 支持地图生命周期自动管理。

### 全局规划器：`planner_server`

- 根据当前位置和目标点生成全局路径。
- 支持绕开地图中的墙体和不可通行区域。
- 支持避免穿越未知区域。
- 支持生成适合机器人行走的路径。
- 支持为空旷区域生成更自然的路径。

### 控制器：`controller_server`

- 根据全局路径计算机器人实际行走速度。
- 控制机器人沿路径前进。
- 支持设置最大行走速度。
- 支持设置最小有效行走速度。
- 支持设置最大转弯速度。
- 支持设置最小有效转弯速度。
- 支持设置加速度和减速度限制。
- 支持接近目标点自动减速。
- 支持急弯自动降速。
- 支持行走过程碰撞预测。
- 支持普通导航不倒车。
- 支持倒走点使用倒走控制。

### 行为服务器：`behavior_server`

- 支持原地旋转恢复。
- 支持等待障碍物离开。
- 支持旋转前进行碰撞检查。
- 支持给行为树提供恢复行为。
- 支持通过等待逻辑处理临时动态障碍。

### 行为树导航器：`bt_navigator`

- 统一调度规划、控制和恢复行为。
- 支持分阶段导航。
- 支持先朝向目标点方向。
- 支持只按 XY 位置到点。
- 支持到点后再对齐最终朝向。
- 支持减少终点附近绕圈和反复调整。
- 支持普通导航行为树。
- 支持倒走导航行为树。

### 自定义行为树插件：`humanoid_nav2_bt_nodes`

- 支持生成朝向目标方向的中间目标。
- 支持最终朝向对齐。
- 支持调用旋转动作完成目标 yaw 调整。
- 支持让人形机器人导航过程更符合“先走到点，再调整朝向”的实际需求。

## 4. 定位、建图与感知系统

### 雷达驱动节点：`rslidar_sdk_node`

- 驱动 RoboSense 雷达。
- 发布实时点云。
- 发布 IMU 数据。
- 为建图、定位和避障提供原始感知数据。

### 激光惯导里程计节点：`fastlio_mapping`

- 实时估计机器人局部运动。
- 发布局部里程计。
- 发布注册点云。
- 支持建图时生成点云地图。
- 为定位系统提供运动估计。
- 为导航系统提供 odom 数据。

### 点云过滤节点：`point_cloud_filter_node`

- 对原始点云进行过滤。
- 去除不适合导航使用的点。
- 输出可用于避障的点云。
- 给局部代价地图提供动态障碍物输入。

### RoboSense 全局定位节点：`robosense_lidar_localization_node`

- 基于已有点云地图进行全局定位。
- 输出机器人在地图中的位置。
- 支持导航过程中的全局定位校正。
- 为 `map -> odom` 桥接提供定位结果。

### 定位桥接节点：`prior_map_odom_bridge`

- 融合全局定位和局部里程计。
- 发布导航所需的 `map -> odom` 坐标关系。
- 保证导航定位连续。
- 支持过滤过期定位数据。
- 支持监控定位大跳。
- 支持输出定位健康状态。
- 支持导航只使用平面位置和朝向。
- 支持为导航状态管理器提供定位异常判断依据。

### 地面坐标发布节点：`dynamic_odom_ground_publisher`

- 发布导航专用地面坐标系。
- 解决雷达/机身高度与导航地面坐标不一致的问题。
- 降低高度漂移对代价地图的影响。
- 提高局部避障和全局地图使用稳定性。

### 机器人实时位姿节点：`robot_realpose_publisher`

- 发布机器人当前全局位姿。
- 支持 APP 地图上显示机器人位置。
- 支持调试时记录机器人实际轨迹。
- 支持导航状态推送中的实时位置展示。

### TF 等待节点：`wait_for_tf`

- 检查关键坐标变换是否可用。
- 确认定位链路稳定后再启动 Nav2。
- 避免导航系统在定位未准备好时提前启动。

### 建图保存节点：`save_pcd_map`

- 支持保存 PCD 点云地图。
- 支持建图完成后触发保存。
- 为后续全局定位提供点云地图。

### 2D 建图节点：`slam_toolbox`

- 支持生成 2D 栅格地图。
- 支持保存 2D 地图。
- 支持保存 posegraph。
- 为 Nav2 地图服务器提供地图。

## 5. 表情与动作系统

### 表情驱动节点：`facial_driver`

- 加载面部表情动作库。
- 接收 APP 下发的表情指令。
- 接收本地 UI 下发的表情指令。
- 通过串口控制面部硬件。
- 支持待机表情。
- 支持惊讶、思考、休眠、兴奋、悲伤等情绪表情。
- 支持说话开始和说话结束表情。
- 支持嘴部不同幅度开合。
- 支持眼球上下左右和居中动作。
- 支持眼睑正常、眯眼、闭眼、凝视等动作。
- 支持眼部快动、慢动、停止。
- 支持对话过程中触发相应嘴部动作。
- 支持对话过程中配合表情变化。
- 支持动作中的延迟控制，保证表情动作按顺序执行。
- 支持节点异常退出后自动重启。

### 表情控制界面：`facial_control_ui`

- 提供本地表情测试界面。
- 支持按钮触发表情。
- 支持现场调试表情动作。
- 支持不经过 APP 直接验证表情硬件。

### 动作控制界面：`gesture_control_gui_plus`

- 提供本地动作库控制界面。
- 支持加载动作列表。
- 支持按动作类型筛选。
- 支持查看动作名称、ID 和说明。
- 支持选择动作并执行。
- 支持向机器人动作控制链路发送动作指令。
- 支持现场调试动作库。
- 支持查看动作执行日志。

### 动作与导航联动能力

- 支持 APP 下发动作控制命令。
- 支持动作执行结果推送给 APP。
- 支持动作完成后通知系统可继续导航。
- 支持动作超时或失败时向 APP 上报。
- 支持导航系统在动作执行期间暂缓启动导航。
- 支持对话、讲解、表情、动作和导航流程配合使用。
