# humanoid_ws 新机器迁移部署说明

本文档基于当前工作区 `/home/ubuntu/humanoid_ws` 的实际代码结构、部署脚本和现有启动方式重新整理，目标是在一台新的 Ubuntu 24.04 机器上，从创建工作空间、拉取 GitHub 最新源码开始，一直到完成编译并成功启动系统。

本文档默认：

- 系统为 `Ubuntu 24.04 LTS`
- ROS 版本为 `ROS 2 Jazzy`
- 仓库地址为 `https://github.com/Lazy-xiaodeng/humanoid_navigation_ws.git`
- 默认工作空间为 `~/humanoid_ws`
- 统一编译命令为：

```bash
colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release
```

## 1. 迁移原则

新机器部署时，不再拷贝旧机器上的 `build/`、`install/`、`log/` 目录，只保留源码和必要资源文件，重新安装依赖、重新编译。

当前仓库已经包含部署所需的关键文件：

- `tools/bootstrap_ubuntu24_jazzy.sh`
- `tools/apt_dependencies_ubuntu24_jazzy.txt`
- `tools/fastdds_shm.xml`
- `start_navigation.sh`
- `stop_navigation.sh`
- `start_mapping.sh`

其中：

- `bootstrap_ubuntu24_jazzy.sh` 负责安装依赖、克隆/更新代码、写入环境变量、执行构建和基础自检
- `start_navigation.sh` 会再次构建一次工作空间，然后启动实机导航入口
- `robot_real.launch.py` 当前默认使用 `relocalization_engine:=ro`，即 RoboSense 定位链路

## 2. 部署目标

部署成功后，至少应满足以下结果：

- 可以正常执行 `source /opt/ros/jazzy/setup.bash`
- 可以正常执行 `source ~/humanoid_ws/install/setup.bash`
- 可以正常执行指定构建命令
- `ros2 pkg list` 能识别 `humanoid_navigation2`、`humanoid_bringup`、`humanoid_websocket`
- 可以通过 `./start_navigation.sh` 拉起整套导航系统

## 3. 推荐部署方式

推荐优先使用仓库自带脚本完成新机器初始化：

```bash
git clone https://github.com/Lazy-xiaodeng/humanoid_navigation_ws.git ~/humanoid_ws
cd ~/humanoid_ws
bash tools/bootstrap_ubuntu24_jazzy.sh
```

如果只是想更新已有工作空间到 GitHub 最新代码：

```bash
cd ~/humanoid_ws
git fetch origin main
git checkout main
git pull --ff-only origin main
```

脚本默认会：

- 校验系统是否为 Ubuntu 24.04
- 安装 ROS 2 Jazzy 软件源
- 安装 `tools/apt_dependencies_ubuntu24_jazzy.txt` 中定义的依赖
- 可选安装 Intel oneAPI
- 安装 `open3d`
- 初始化 `rosdep`
- 拉取或更新工作区代码
- 生成 `~/.config/fastdds_shm.xml`
- 向 `~/.bashrc` 追加 ROS 和工作空间环境
- 执行构建和基础自检

如果你希望完全手动部署，按第 4 节开始执行。

## 4. 手动部署流程

### 4.1 创建工作空间并下载最新源码

```bash
mkdir -p ~/humanoid_ws
cd ~/humanoid_ws
git clone https://github.com/Lazy-xiaodeng/humanoid_navigation_ws.git .
git checkout main
git pull --ff-only origin main
```

如果目录已经存在但还不是 Git 仓库，先备份原目录后再重新克隆，不建议把旧机器的 `build/ install/ log/` 直接搬到新机器。

### 4.2 确认系统版本

```bash
cat /etc/os-release
```

应看到：

- `ID=ubuntu`
- `VERSION_ID="24.04"`

### 4.3 安装基础工具

```bash
sudo apt update
sudo apt install -y \
  build-essential \
  cmake \
  curl \
  git \
  gnupg \
  locales \
  lsb-release \
  python3-pip \
  software-properties-common \
  wget
```

建议同时设置 locale：

```bash
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8
```

## 5. 安装 ROS 2 Jazzy

### 5.1 配置 ROS 软件源

```bash
sudo apt update
sudo apt install -y curl gnupg lsb-release software-properties-common
sudo add-apt-repository -y universe

sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  -o /usr/share/keyrings/ros-archive-keyring.gpg

echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo "$UBUNTU_CODENAME") main" \
  | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
```

### 5.2 安装 ROS 2 Jazzy 和工作空间工具

```bash
sudo apt update
sudo apt install -y \
  ros-jazzy-desktop-full \
  python3-colcon-common-extensions \
  python3-rosdep \
  python3-vcstool
```

### 5.3 配置 ROS 环境

```bash
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc
source /opt/ros/jazzy/setup.bash
```

验证：

```bash
echo $ROS_DISTRO
ros2 --help
```

其中 `ROS_DISTRO` 应输出 `jazzy`。

## 6. 安装工作空间依赖

### 6.1 按仓库依赖清单安装 apt 包

仓库已提供依赖清单 `tools/apt_dependencies_ubuntu24_jazzy.txt`，建议直接使用：

```bash
cd ~/humanoid_ws
sudo apt update
sudo xargs -a tools/apt_dependencies_ubuntu24_jazzy.txt apt install -y
```

如果 `xargs` 因注释行导致报错，可改用脚本方式安装：

```bash
cd ~/humanoid_ws
grep -Ev '^\s*($|#)' tools/apt_dependencies_ubuntu24_jazzy.txt | xargs sudo apt install -y
```

这一步会安装：

- ROS 2 Jazzy 桌面和 Nav2 相关依赖
- `pcl`、`opencv`、`octomap`、`yaml-cpp`、`OpenCL` 等本地库
- `python3-websockets`、`python3-yaml`、`python3-numpy` 等 Python 包

### 6.2 初始化 rosdep

首次部署新机器时执行：

```bash
sudo rosdep init
rosdep update
```

如果提示已初始化，只需继续执行：

```bash
rosdep update
```

### 6.3 使用 rosdep 补齐源码依赖

```bash
source /opt/ros/jazzy/setup.bash
cd ~/humanoid_ws
rosdep install --from-paths src --ignore-src --rosdistro jazzy -r -y \
  --skip-keys "ament_python apr elevation_mapping elevation_mapping_cupy grid_map_cmake_helpers lidar_localization lidar_localization_ros2 open3d_loc ros2bag websockets"
```

说明：

- 这些 `skip-keys` 来自当前仓库的 `tools/bootstrap_ubuntu24_jazzy.sh`
- 它们里有一部分是历史 key、局部自定义 key 或当前环境不稳定的 key
- 跳过后再通过 apt 和 pip 手动补齐，更贴合当前仓库的真实部署方式

### 6.4 安装 Open3D

```bash
python3 -m pip install --user --break-system-packages open3d
```

如果安装失败，不一定影响所有功能，但会影响依赖 Open3D 的相关定位或工具链。

## 7. 可选安装 Intel oneAPI

如果新机器要跑 OpenCL/SYCL 相关加速，建议安装；如果只是先跑通系统，也可以先跳过。

```bash
wget -O- https://apt.repos.intel.com/intel-gpg-keys/GPG-PUB-KEY-INTEL-SW-PRODUCTS.PUB \
  | gpg --dearmor \
  | sudo tee /usr/share/keyrings/oneapi-archive-keyring.gpg > /dev/null

echo "deb [signed-by=/usr/share/keyrings/oneapi-archive-keyring.gpg] https://apt.repos.intel.com/oneapi all main" \
  | sudo tee /etc/apt/sources.list.d/oneAPI.list > /dev/null

sudo apt update
sudo apt install -y \
  intel-oneapi-basekit \
  intel-oneapi-dpcpp-cpp \
  intel-oneapi-opencl-rt \
  intel-opencl-icd
```

## 8. 配置运行环境

### 8.1 配置 FastDDS

当前仓库默认使用 FastDDS 共享内存优化。执行：

```bash
mkdir -p ~/.config
cp ~/humanoid_ws/tools/fastdds_shm.xml ~/.config/fastdds_shm.xml
```

### 8.2 将工作空间环境写入 `~/.bashrc`

将以下内容追加到 `~/.bashrc` 末尾：

```bash
export ROS_DISTRO=jazzy
export ROS_DOMAIN_ID=${ROS_DOMAIN_ID:-0}
export RMW_IMPLEMENTATION=${RMW_IMPLEMENTATION:-rmw_fastrtps_cpp}
export FASTRTPS_DEFAULT_PROFILES_FILE=${FASTRTPS_DEFAULT_PROFILES_FILE:-$HOME/.config/fastdds_shm.xml}
export RMW_FASTRTPS_USE_QOS_FROM_XML=${RMW_FASTRTPS_USE_QOS_FROM_XML:-1}

source /opt/ros/jazzy/setup.bash

if [ -f /opt/intel/oneapi/setvars.sh ]; then
  source /opt/intel/oneapi/setvars.sh > /dev/null 2>&1
fi

if [ -f ~/humanoid_ws/install/setup.bash ]; then
  source ~/humanoid_ws/install/setup.bash
fi
```

生效：

```bash
source ~/.bashrc
```

## 11. 运行方式

### 11.1 推荐启动方式

当前仓库根目录提供一键导航启动脚本：

```bash
cd ~/humanoid_ws
./start_navigation.sh
```

该脚本会：

- 加载 ROS 环境
- 检查 FastDDS 环境变量
- 再次执行一次编译
- `source install/setup.bash`
- 清理上一次残留导航进程
- 最终启动：

```bash
ros2 launch humanoid_bringup robot_real.launch.py use_sim_time:=false
```

其中 `robot_real.launch.py` 内部会继续拉起：

- `humanoid_description`
- `humanoid_navigation2`
- `humanoid_navigation`
- `humanoid_websocket`
- `humanoid_locomotion`
- RViz

并且当前默认定位链路是：

```text
relocalization_engine:=ro
```

也就是 RoboSense 激光定位链路。

### 11.2 停止导航

```bash
cd ~/humanoid_ws
./stop_navigation.sh
```

### 11.3 建图启动

如果要进入建图流程，可使用：

```bash
cd ~/humanoid_ws
./start_mapping.sh
```

## 13. 常见问题

### 13.1 `rosdep install` 失败

优先确认：

- 已执行 `source /opt/ros/jazzy/setup.bash`
- 已执行 `rosdep update`
- 使用了本文档中的 `--skip-keys`

如果是个别 Python 包问题，通常直接用 `pip install --user` 补齐更快。

### 13.2 `open3d` 安装失败

先确认：

```bash
python3 --version
pip3 --version
```

再重试：

```bash
python3 -m pip install --user --break-system-packages -U pip
python3 -m pip install --user --break-system-packages open3d
```

### 13.3 构建后找不到包

确认是否执行：

```bash
source /opt/ros/jazzy/setup.bash
source ~/humanoid_ws/install/setup.bash
```

必要时全量重编：

```bash
cd ~/humanoid_ws
rm -rf build install log
colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release
```

### 13.4 导航启动后立即退出

先查看启动日志目录：

```bash
ls ~/humanoid_ws/debug_logs
```

重点检查：

- 地图/点云文件是否存在
- `install/setup.bash` 是否已生成
- `websockets`、`yaml`、`numpy` 是否可导入
- 是否存在旧进程残留
- 激光雷达、机器人底盘、网络接口是否已正常连接

## 14. 最小闭环部署命令
